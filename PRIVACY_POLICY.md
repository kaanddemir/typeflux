# Privacy Policy
Last Updated: March 1, 2026

## TypeFlux Chrome Extension

### Overview
**TypeFlux** is a browser extension that provides live typography preview for any website. Users can test fonts, spacing, and hierarchy with instant results. We are committed to protecting your privacy and follow a user-initiated approach — the extension only runs when you explicitly interact with it.

### Data Collection
We do not collect any personal data.

This extension:
*   **Does NOT** collect personal information
*   **Does NOT** track your browsing history
*   **Does NOT** send any data to external servers
*   **Does NOT** use analytics or tracking tools
*   **Does NOT** run automatically on any page

### Data Processing
The extension processes the content of the active tab locally on your device to read current typography values and apply CSS overrides. This data is:
*   Processed in real-time within your browser's memory
*   Never transmitted to any external server
*   Discarded immediately when you refresh the page, close the extension, or close the tab

### How It Works
*   The extension does not inject any scripts automatically into web pages
*   Scripts are only injected after you click the extension icon or trigger a specific action
*   The extension only accesses the currently active tab after a user gesture
*   All typography changes are temporary CSS overrides — no page content is modified permanently

### Permissions
The extension requests minimal permissions:

| Permission | Purpose |
| :--- | :--- |
| `activeTab` | Access only the current tab, and only after you interact with the extension |
| `scripting` | Dynamically inject the typography engine code when you activate it |

### Third-Party Services
The only external connection TypeFlux makes is to **Google Fonts** (`fonts.googleapis.com`) to load font families selected by the user. No user data is included in these requests — only the font name is sent as part of the standard CSS URL. No other third-party services, APIs, advertisement networks, or analytics are used.

### Data Sharing
Since we do not collect any data, we have no personal information to share, sell, or trade with any third parties.

### Security
Because TypeFlux runs entirely locally on your device and does not transmit user data over the internet, your exposure to remote security risks via this extension is non-existent.

### User Control
You have full control over the extension:
*   **On-Demand**: The extension only runs when you ask it to.
*   **Non-Persistent**: All changes disappear on page refresh — nothing is saved.
*   **Transparency**: You can view the source code to verify these claims.

### Changes to This Policy
If we make changes to this privacy policy, we will update the "Last Updated" date above.

### Contact
If you have any questions about this privacy policy, please open an issue on our GitHub repository.

### Summary
TypeFlux works entirely locally. It only runs when you explicitly use it, and your data never leaves your device. The sole external connection is to Google Fonts for loading typefaces you select.
